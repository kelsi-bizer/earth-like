# How Fans Change the Story

Fans are **in-universe participants** ("Terra Watch" volunteers / citizen scientists). They can:
1. **Vote** at author-defined **branch points** (`branches:` in the tracker). Winner → ledger → author accepts/overrides.
2. **Submit findings** (e.g., decode a clue in a public data drop). Verified findings can unlock beats early.
3. **Talk to characters** — conversations become *fan-interaction* memories (low importance) that characters may reference.
4. **Propose** ideas (never auto-canon). The author approves.

## Rules
- Branches are designed so every option **rejoins the spine within 2 chapters**.
- One person, one vote per branch; first vote wins; accounts are rate-limited (adapter responsibility).
- Fans can **never** edit `locked` canon. Ledger entries start `author_review: pending`.
- Credit fans in-universe (named contributors list, "Terra Watch" credits).
- Votes close at `deadline_days`; ties go to the earlier-listed option (documented, deterministic).
